# backend/AGENTS.md — Go-сервис

Дополняет корневой [AGENTS.md](../AGENTS.md). Общие правила (SDD, git, права, покрытие) действуют здесь полностью.

## Назначение
API для фронтенда, оркестрация AI-агента (диалог, вызов инструментов), проверка прав, интеграции с корпоративными сервисами (имитациями из `mocks/`), хранение состояния онбординга.

## Рекомендуемая структура (уточняется спекой / ADR)
```
cmd/server/          точка входа
internal/
  api/               HTTP-хендлеры, DTO, валидация входа
  agent/             диалог, промпты, цикл вызова инструментов
  llm/               интерфейс провайдера LLM + реализации + fake для тестов
  tools/             инструменты агента (MCP-стиль): схема входа/выхода, вызов сервиса
  integrations/      клиенты корпоративных сервисов (против имитаций)
  authz/             роли и проверка прав
  onboarding/        этапы, статусы задач, следующие шаги
  storage/           PostgreSQL, Redis
```

## Правила
- Go — версия фиксируется в `go.mod`. Форматирование `gofmt`/`goimports`, линтер `golangci-lint`.
- Зависимости внутрь: `api` → доменные пакеты → `storage`/`integrations`. Доменная логика не знает про HTTP.
- Внешние зависимости (LLM, сервисы, БД) — за интерфейсами, чтобы подменять фейками в тестах.
- **LLM-провайдер** выбирается конфигурацией (`LLM_PROVIDER`, `LLM_MODEL`, ключ — отдельная переменная). Конкретная модель пока не выбрана — не хардкодь её.
- Каждый вызов LLM и внешнего сервиса — с `context.Context`, таймаутом и обработкой ошибки. Ошибка превращается в понятный пользователю статус, а не в 500 без объяснений.
- Проверка прав — до вызова инструмента и до формирования промпта. Тест на отказ в доступе обязателен для каждого инструмента.
- Ошибки оборачиваем `fmt.Errorf("...: %w", err)`; логи структурированные (`log/slog`), без ПДн и секретов.

## Тесты
- Табличные тесты, пакет `testing` (+ `testify`, если команда решит).
- Покрытие: `go test ./... -coverprofile=coverage.out` → `go tool cover -func=coverage.out`. Порог > 80% по прикладному коду; `cmd/` и сгенерированный код исключаются.
- Реальная LLM в тестах не вызывается.
