# frontend/AGENTS.md — React-приложение

Дополняет корневой [AGENTS.md](../AGENTS.md). Общие правила (SDD, git, покрытие) действуют здесь полностью.

## Назначение
Интерфейс стажёра: **веб-чат** с AI-buddy и **панель «мой онбординг»** — этапы адаптации, статусы задач, следующие шаги, история выполненных действий.

## Стек
React + TypeScript (strict), TanStack Query (запросы к API), TanStack Router, Zustand (клиентское состояние), Zod (валидация ответов API и форм). Сборка — Vite (если команда не решит иначе в ADR).

## Рекомендуемая структура (уточняется спекой / ADR)
```
src/
  api/          API-клиент + Zod-схемы ответов
  features/
    chat/       чат, сообщения, статусы ожидания, подтверждение действий
    onboarding/ этапы, задачи, следующие шаги
  components/   переиспользуемые UI-компоненты
  stores/       Zustand-сторы
  routes/
```

## Правила
- Все ответы API проходят через Zod-схемы — никаких `any` и непроверенных данных.
- Явный API-клиент с базовым URL из конфигурации (кейс требует его при отдельном размещении статики).
- Фронтенд **не решает вопросы прав** — только отображает то, что вернул бэкенд.
- Отзывчивость: локальные действия мгновенно (< 1 с); запросы к LLM — с индикатором ожидания, возможностью повторить и понятным сообщением об ошибке. Интерфейс не блокируется.
- Действия, меняющие состояние (например, оформление отгула), показываются пользователю с подтверждением и затем с результатом.
- Тексты интерфейса — на русском.

## Тесты
- Vitest + React Testing Library; сеть — через MSW.
- Покрытие: `vitest run --coverage`, порог > 80% по прикладному коду.
