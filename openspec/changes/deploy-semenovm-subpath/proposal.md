# Proposal

## Why

Стажёр и жюри должны открывать прототип по HTTPS без локальной установки. Это позволяет демонстрировать сценарии онбординга, снимающие с наставника организационную рутину.

## What Changes

- Настраиваем базовый путь интерфейса, API и демонстрационных документов для `/avito_buddy/`.
- Разворачиваем отдельный Docker Compose-проект на 177.202.73.214 за существующим nginx домена semenovm.ru.
- Проверяем HTTPS, вход, план, чат и сохранение данных.
- Вне области: новые сценарии, настоящие корпоративные сервисы, выбор LLM и изменение других сайтов.

## Capabilities

### New Capabilities

- `subpath-hosting`: размещение прототипа под настраиваемым префиксом URL.

### Modified Capabilities

Нет.

## Impact

Frontend: базовый путь Vite/Router, URL API и документов. Инфраструктура: отдельный Compose override, nginx location, секреты только на сервере. Зависимости не добавляются. Пользователь 14.11.2026 явно разрешил необходимые правки и деплой после сообщения о необходимости базового пути.
