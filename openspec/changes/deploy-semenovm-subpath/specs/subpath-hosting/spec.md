# Spec Delta

## Purpose

Обеспечить доступ к демонстрационному прототипу по HTTPS под префиксом URL на общем сервере с другими приложениями.

## ADDED Requirements

### Requirement: Настраиваемый базовый путь
Интерфейс SHALL поддерживать корень сайта и заданный при сборке префикс. Роутер, статика, запросы API и внутренние ссылки на демонстрационные документы SHALL работать после перезагрузки страницы.

#### Scenario: Размещение под префиксом
- **WHEN** пользователь открывает `/avito_buddy/` и выбирает демо-профиль
- **THEN** отображается рабочее пространство, API вызывается через `/avito_buddy/api/`, документы открываются через `/avito_buddy/demo/docs/`

#### Scenario: Локальный запуск
- **WHEN** префикс не задан
- **THEN** сохраняются адреса `/`, `/api/` и `/demo/docs/`

### Requirement: Изолированный демо-стенд
Стенд SHALL запускаться отдельным Compose-проектом с постоянными томами и автоматическим перезапуском. БД, Redis, API и имитации MUST не открывать публичные порты. HTTPS SHALL обслуживаться существующим nginx без изменения маршрутов других приложений.

#### Scenario: Доступ через домен
- **WHEN** пользователь открывает `https://semenovm.ru/avito_buddy`
- **THEN** получает перенаправление на завершающий `/` и рабочий интерфейс с действительным TLS-сертификатом

### Requirement: Сохранение прав и устойчивости
Публикация SHALL сохранять серверную авторизацию, подтверждения действий и понятные ответы при отказе прав, таймауте LLM или сервиса. Данные и история SHALL сохраняться после перезапуска контейнеров.

#### Scenario: Неавторизованный запрос
- **WHEN** браузер без сессии запрашивает `/avito_buddy/api/me`
- **THEN** сервер отвечает 401 без данных профиля

#### Scenario: Детерминированная демонстрация
- **WHEN** выбран режим fake и пользователь отправляет вопрос
- **THEN** ответ обрабатывается без внешнего вызова LLM, интерфейс остаётся доступным во время ожидания
