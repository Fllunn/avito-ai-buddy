# Tasks

Работа ведётся по трём спецификациям этого change и неизменённым бизнес-контрактам `build-onboarding-prototype`. Выполнение отмечается только после реализации и соответствующих проверок. Выбор окончательного маскота блокирует только его финальную графику и визуальную приёмку, независимые задачи продолжаются.
