Правила папки:
- Чек-лист стажёра (материал организаторов) приведён **полностью**. Остальное — **подробные конспекты своими словами** со ссылками на оригиналы: у репозиториев нет лицензии, статьи защищены авторским правом.

## Главное для AI-buddy (коротко)

1. **Каркас онбординга** — из чек-листа: неделя 1 → неделя 2 → месяц 1–3 → экватор → выпускной. Роли: стажёр, бадди, руководитель, куратор стажировки. → [checklist.md](checklist.md)
2. **Боли стажёров:** доступы в первый день, непонятный Scrum, страх дёргать занятого наставника, нужны еженедельные 1:1 и цели развития. → [habr.md §1](habr.md#1-стажировки-наставники-онбординг)
3. **В Авито уже есть похожее:** ассистент «Виталик» (RAG + MCP Hub + approvals + бенчмарки), бот Sheldon (статусы, напоминания, действия). AI-buddy стоит строить по той же архитектуре. → [habr.md §2–3](habr.md#2-корпоративные-ии-агенты-и-llm-в-авито)
4. **Критерии ревью Авито для нашего стека** (Go, PostgreSQL, React, Docker Compose, мок-LLM, история запусков LLM со статусами). → [tech-internship.md](tech-internship.md)
5. **SDD и OpenSpec** Авито применяет сам — это сильный аргумент на защите. → [habr.md §2](habr.md#2-корпоративные-ии-агенты-и-llm-в-авито) (статья «Агентская разработка»)
6. **Справочные ответы бота** (SPT, ZBP, PaaS, LSR, OKR, E1…) — по открытому Playbook и со ссылкой на него. → [playbook.md](playbook.md)
7. **API в стиле Авито:** ошибки `{error:{code,message}}`, 409 — бизнес-отказ, 502 — сбой LLM; пагинация; история запусков `pending/success/failed`. → [tech-internship.md](tech-internship.md#api-контракт-задания-apiyaml-openapi--выжимка)
8. **Провайдеры LLM:** детерминированный мок по умолчанию, Ollama локально без ключа (так предлагает сам Авито), OpenAI-совместимый API через env. → [tech-internship.md](tech-internship.md#frontend-весна-2026-ai-ассистент-для-улучшения-объявлений)
9. **Роли из профилей Авито:** бадди ≈ инженер E4 («занимается онбордингом новичков»), руководитель ≈ M1 («организует онбординг, ставит цели на испытательный срок»). → [playbook.md](playbook.md#профили-инженеров-e1e8)
10. **Права — централизованно на бэкенде** (в PaaS Авито — отдельный сервис авторизации на OPA с ролями на сущность). → [habr.md §4](habr.md#4-второй-заход-права-go-надёжность)

## Чего нет в открытом доступе

Внутренние сущности из чек-листа не раскрыты нигде: avito-cli (кроме общего описания PaaS), stash-ключи, канал Tech-dep, Observer, инфомодель, Шаталити, Демо Tech Platform, Центр сообществ, учебная платформа, лендинг «Защита данных», политика КИ, методичка наставника. В моках они могут быть только **выдуманными демо-заглушками с явной пометкой**.
