# Чек-лист стажёра Авито

> Источник: [Google-таблица «Чек-лист стажера»](https://docs.google.com/spreadsheets/d/1qKFqOzfSZ2jEz57jBSmq7rukDXi_tRfWohgemViceV0/edit?gid=1073060303#gid=1073060303) — материал организаторов кейса.
> Снято: 2026-11-11. Ниже содержимое таблицы полностью, без сокращений. Колонка «Кто» и сноски — наши пометки, в оригинале их нет.

Таблица — две вкладки:

1. **«Материалы для всех»** — общие шаги адаптации для всех стажёров. Одни пункты адресованы стажёру, другие — бадди / руководителю. Отдельной колонки с ролью в таблице нет; роль понятна из текста пункта (`Добавь стажёра…` — это бадди).
2. **«Чек-лист Backend»** — специальные материалы для Backend-стажёров.

Колонки: «Материалы чек-листа» (название пункта), «Описание пункта» (подшаги, есть только на первой вкладке), «Период прохождения задачи».

Периоды: `1 неделя`, `2 неделя`, `1 месяц`, `2 месяц`, `3 месяц`, `После 3-х месяцев`. Стажировка длится больше 3 месяцев; в середине — **экваторная встреча**, в конце — **выпускной**.

## Что это значит для AI-buddy (наши выводы)

- **Этапы онбординга** берём из таблицы: неделя 1 → неделя 2 → месяц 1 → месяц 2 → месяц 3 → экватор → выпускной. Это готовый каркас панели «мой онбординг».
- **Роли** в таблице — стажёр, бадди (наставник), руководитель и **куратор стажировки** (HR / программа стажировок). Куратор выдаёт методичку и инструмент отслеживания прогресса, помогает оформить презентацию. По кейсу его роль ближе всего к HR BP.
- **Задачи бывают двух типов:** «изучи / пройди / расскажи» (обучение; закрывает сам стажёр) и «запроси / добавь / назначь» (организационные; нужны действия в сервисах). Вторые — кандидаты на инструменты агента: запрос доступа, добавление в чаты, назначение встречи 1:1, бронирование репетиции на 15 минут.
- **Внутренние сущности Авито**, которые упоминаются, но не раскрываются: avito-cli, stash, канал Tech-dep, SPT, ZBP, Observer, PaaS-дашборд, инфомодель, Шаталити, Демо Tech Platform, Центр сообществ, учебная платформа, лендинг «Защита данных», политика КИ. Их содержания нет в открытом доступе. В моках — только как **демонстрационные** заглушки, без выдумывания «настоящих» регламентов.
- **«Расскажи о Grafana / Sentry / Observer / Redash»** — проверка понимания. Бот может предложить стажёру коротко рассказать о себе и дать обратную связь (сценарий «квиз / самопроверка»).
