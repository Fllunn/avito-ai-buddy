# 0010. OpenRouter и модель из конфигурации

- **Статус:** принято
- **Дата:** 2026-11-14

## Контекст

Пользователь выбрал OpenRouter; конкретную модель решено не фиксировать в коде. Решение относится к задачам 8.1–8.2 утверждённого change build-onboarding-prototype.

## Решение

Адаптер реализует существующий интерфейс agent.Provider через стандартный Go net/http, без SDK. `LLM_PROVIDER=openrouter`, `LLM_MODEL=<идентификатор модели>` и `OPENROUTER_API_KEY` обязательны для реального режима; fake остаётся детерминированным режимом тестов. Никакая модель не выбирается автоматически. POST https://openrouter.ai/api/v1/chat/completions передаёт Bearer-ключ, model, messages, stream=false, max_tokens=2048 и response_format=json_object. Распознавание возвращает только намерения/параметры; ответ по документам — только идентификаторы и границы фрагментов. Доменные проверки и подтверждения остаются в Go.

Код проверяет HTTP-статус, JSON, отсутствие ошибки/вызовов инструментов, finish_reason и непустое содержимое. Любая ошибка, таймаут, лимит или несовместимая модель включает существующий кнопочный путь. Тела ошибок и ключ не включаются в ошибки/логи. Вход проходит локальную очистку и фильтр прав до адаптера. Запрос ограничен context и LLM_TIMEOUT; автоматических платных повторов HTTP нет. Единственная допустимая повторная генерация ответа ограничена общим таймаутом Answerer.

Стоимость зависит от выбранной модели и числа входных/выходных токенов; фиксированную цену без выбранной модели не заявляем. Перед реальным прогоном владелец задаёт модель и проверяет её тариф и поддержку JSON. 402 означает ограничение средств, 429 — лимит запросов; оба ведут к безопасному fallback. Лимиты бесплатных моделей зависят от аккаунта и могут меняться. Реальный режим принимается отдельно с настроенным ключом; fake HTTP не доказывает качество выбранной модели.

Официальные источники, проверены 14.11.2026: [протокол](https://openrouter.ai/docs/api-reference/overview), [лимиты и кредиты](https://openrouter.ai/docs/api-reference/limits), [каталог моделей и тарифы](https://openrouter.ai/models). Проверка остатка лимита — GET /api/v1/key; приложение не обращается к нему автоматически.

## Альтернативы и последствия

SDK добавил бы зависимость для одного HTTP endpoint. Привязка к одной модели затруднила бы замену на хакатоне. Конфигурируемая модель сохраняет заменяемость, но её совместимость и качество нужно проверять при смене значения; невалидный вывод не исполняется.
