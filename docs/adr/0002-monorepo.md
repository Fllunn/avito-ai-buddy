# 0002. Монорепозиторий

- **Статус:** принято
- **Дата:** 2026-11-09

## Контекст
Команда из 4 человек, хакатон длится неделю. Сдача — один репозиторий или ZIP с кодом, спеками, тестами и документацией; запуск через Docker должен поднимать всё сразу.

## Решение
Один репозиторий на GitHub: `backend/`, `frontend/`, `mocks/`, `openspec/`, `docs/`. Работа в ветках, слияние в `main` через PR.

## Альтернативы
- **Отдельные репозитории для фронта и бэка** — сложнее синхронизировать контракты и спеки, сложнее сдавать.

## Последствия
- Одна спека описывает изменение сквозь фронт и бэк.
- Один `docker compose` поднимает весь прототип.
- Разделение по папкам позволяет работать параллельно с минимумом конфликтов.
