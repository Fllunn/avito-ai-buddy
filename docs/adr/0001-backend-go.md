# 0001. Бэкенд на Go

- **Статус:** принято
- **Дата:** 2026-11-09

## Контекст
Кейс оценивает совместимость архитектуры со стеком Авито: бэкенд преимущественно на Go, Python + Flask — в отдельных случаях. «Внедряемость и интеграции» — 30% онлайн-оценки и 25% финала.

## Решение
Бэкенд, оркестрация агента и инструменты — на Go. Хранилища — PostgreSQL и Redis.

## Альтернативы
- **Python + Flask** — богаче экосистема LLM-библиотек, но для Авито это исключение, а не основной стек.
- **Go + отдельный Python AI-сервис** — лишний сервис и межсервисное взаимодействие без явной выгоды для прототипа.

## Последствия
- Плюс к внедряемости: решение ложится на основной стек Авито.
- LLM-клиент и цикл вызова инструментов пишем сами или на лёгких Go-библиотеках — закладываем время.
