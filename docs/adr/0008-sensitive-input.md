# 0008. Очистка чувствительного ввода до хранения

- **Статус:** принято
- **Дата:** 2026-11-13

## Контекст

Пользователь может прислать медицинские, семейные сведения или секреты, хотя сервису нужны только даты.

Основание: утверждённый [design.md](../../openspec/changes/build-onboarding-prototype/design.md), change `build-onboarding-prototype`.

## Решение

Локальный очиститель работает до БД и LLM. Проверяемые категории маскируются; сомнение или ошибка приводят к замене всего сообщения маркером и кнопочной форме. Сырой текст и его хэш не сохраняются. В карточку, сервис, события и логи попадают только разрешённые поля. Ответы и ошибки не повторяют чувствительный ввод. Причина отсутствия не запрашивается.

## Альтернативы

Очистка только промпта оставляет данные в истории; внешняя LLM для очистки уже раскрывает вход третьей стороне.

## Последствия

Гарантия ограничена синтетическим корпусом тестов, а не произвольным естественным языком. Перед внедрением нужна отдельная оценка. Закрытый режим иногда потребует повторного ввода через форму.
