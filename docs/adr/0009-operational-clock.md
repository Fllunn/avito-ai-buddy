# 0009. Независимые бизнес-часы и часы очереди

- **Статус:** принято пользователем
- **Дата:** 2026-11-13

## Контекст

DEMO_NOW фиксирует общую дату API и имитаций для воспроизводимых календарных примеров. Если использовать тот же неподвижный Clock для jobs, будущий момент сверки и истечение lease никогда не наступают.

## Решение

Оставить бизнес-Clock для правил и дат, сроков карточек/подтверждений и пользовательских отметок. Операционный Clock реального UTC-времени определяет расписание очереди, lease и техническую длительность. Операционные моменты сохраняются в PostgreSQL, включая отдельный момент подтверждения попытки; перезапуск не начинает ожидание заново. В тестах оба Clock управляются независимо.

Уточнение OpenSpec утверждено в чате 13.11.2026: «Да, разделить часы».

## Альтернативы

Продвижение DEMO_NOW вместе с реальным временем меняет даты воспроизводимых примеров; фиксация одного Clock останавливает очередь. Счётчики задержки только в памяти теряются при перезапуске.

## Последствия

У доменных и операционных мгновений явные разные назначения. В тестах проверяется продвижение очереди при неизменной бизнес-дате. Общий бизнес-Clock API/имитаций сохраняется.
