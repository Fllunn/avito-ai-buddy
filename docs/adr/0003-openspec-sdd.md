# 0003. Spec-Driven Development через OpenSpec

- **Статус:** принято
- **Дата:** 2026-11-09

## Контекст
Кейс требует разрабатывать AI-сценарии по SDD и приложить спецификации (упомянуты spec-kit и OpenSpec). Код пишут в основном ИИ-агенты разных вендоров — им нужна однозначная спецификация поведения.

## Решение
OpenSpec 1.16.1, схема `spec-driven`: proposal → specs → design → tasks. Артефакты на русском, ключевые слова SHALL/MUST — на английском. Скиллы установлены в универсальном формате (`.agents/skills/`), чтобы работать с любым агентом. Правила проекта для артефактов — в `openspec/config.yaml`.

## Альтернативы
- **spec-kit** — более формальный процесс (constitution, plan, tasks), тяжелее для недельного хакатона.
- **Свой шаблон** — без валидации и готового процесса; жюри проще узнать известный инструмент.

## Последствия
- Каждое изменение проходит через change-proposal и ревью человеком до реализации.
- Спеки в `openspec/specs/` + архив изменений — готовое доказательство SDD для сдачи.
- Участникам нужен Node.js для CLI OpenSpec. CLI собирает анонимную телеметрию; отключение — `OPENSPEC_TELEMETRY=0`.
