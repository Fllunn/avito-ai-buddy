# 0005. Модульный API и изолированные HTTP-имитации

- **Статус:** принято
- **Дата:** 2026-11-13

## Контекст

Прототип должен сохранять границы корпоративных сервисов без инфраструктуры микросервисов.

Основание: утверждённый [design.md](../../openspec/changes/build-onboarding-prototype/design.md), change `build-onboarding-prototype`.

## Решение

Один модульный Go API; доменные пакеты не зависят от HTTP. Отдельный Go-процесс имитаций обслуживает доступы и отсутствия через независимые JSON API. PostgreSQL общий как инсталляция, но базы, владельцы и роли API и имитаций раздельные. API не имеет доступа к таблицам имитаций. Общие примитивы времени и конфигурации находятся в экспортируемом пакете backend/platform, который имитации подключают локальной Go-зависимостью; доменную логику между процессами не разделяем.

## Альтернативы

Микросервисы помощника усложняют запуск; общие таблицы скрывают ошибки интеграций.

## Последствия

Можно заменить HTTP-имитации реальными адаптерами. Требуются контрактные тесты и отдельные миграции двух владельцев данных.
