# 0004. Инструкции для ИИ-агентов: AGENTS.md как источник правды

- **Статус:** принято
- **Дата:** 2026-11-09

## Контекст
Команда использует разных ИИ-агентов. `AGENTS.md` — открытый стандарт (Codex, Cursor, Copilot, Gemini CLI и др.); Claude Code читает `CLAUDE.md`, но поддерживает импорт `@файл`.

## Решение
- Все правила — в корневом `AGENTS.md`; `CLAUDE.md` импортирует его (`@AGENTS.md`) и добавляет только Claude-специфику.
- Во вложенных папках (`backend/`, `frontend/`, `mocks/`) — свои `AGENTS.md` с локальными правилами и тонкий `CLAUDE.md` с импортом.
- Контекст для агентов не дублируется в отдельной папке: `AGENTS.md` — короткое оглавление со ссылками на `docs/` (progressive disclosure).
- **Коммиты, push и PR делает только человек.** Агенты готовят изменения в рабочей копии и могут предложить текст коммита.

## Альтернативы
- Отдельные полные файлы для каждого агента — правила расходятся.
- Симлинк `CLAUDE.md → AGENTS.md` — ненадёжно на Windows в git.
- Отдельная папка `context/` для агентов — дублирует `docs/`.

## Последствия
- Правило меняется в одном месте и сразу действует для всех агентов.
- Человек контролирует историю репозитория и всё, что уходит на GitHub.
