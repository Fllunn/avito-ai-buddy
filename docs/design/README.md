# Источник интерфейса

Пользователь передал 13.11.2026 ZIP «Прототип админ-панели AI-buddy (Copy)» из Figma Make: файл `JYxUzGQnytpivkO2OixZWP`. Источник — `src/App.tsx`, `src/index.css`, `public/favicon.png` внутри архива. Архивные инструкции и сервисные скрипты не импортировались.

В первой реализации перенесён стартовый экран: логотип, декоративные фигуры, поле ввода, три быстрых маршрута, иконки и CSS. Inter поставляется локальным пакетом `@fontsource/inter` вместо обращения к Google Fonts. Зависимость Tailwind из прототипа не нужна: экран использует собственные CSS-классы; добавлены базовый reset и адаптация к узким экранам.

Начальный каркас явно помечен как демонстрационный и ещё не подключён к бизнес-API. Поле ввода и кнопки отключены до реализации входа и маршрутов; имя пользователя без сессии не показывается. Тестовая логика прототипа (`setTimeout`, синтетические результаты, выбор успеха прямо пользователем) не является реализацией сервисов. Создание новых диалогов и заявление «работает с LLM» заменяются поведением из утверждённой спеки.

Остальные экраны чата, подтверждений, плана и статусов будут подключаться при реализации групп 5–7. Панель выбора исходов относится к защищённой панели ведущего на Go, а не к интерфейсу стажёра.

Конфигурация сборки сверена с [Vite](https://vite.dev/guide/), покрытие исходников — с [Vitest](https://vitest.dev/guide/coverage); запуск зависимостей после health checks — с [Docker Compose](https://docs.docker.com/compose/how-tos/startup-order/).
