# Личное пространство AI-buddy

Основание: [утверждённый дизайн](../../openspec/changes/redesign-buddy-experience/design.md) и [исследование](../sources/avito-design-research.md). Это собственный интерфейс прототипа, не официальная библиотека Авито. Локальный Inter из установленного `@fontsource/inter`; сетевых шрифтов нет.

## Композиция

Desktop ≥1024 px: шапка с демо и профилем; основной столбец с персональным контекстом, одним главным следующим шагом и разговором; справа сводка периода, ожидания и кнопка полного плана. Главный заголовок 28/34, секция 21/26, основной текст 15/22, плотный текст 15/20, подпись 13/18. Отступы кратны 2 px; радиусы 6/12/16/24 по роли контрола/карточки/панели.

Mobile: одна колонка, чат и главный шаг; «Мой онбординг» открывает отдельную панель. Ввод остаётся в потоке с safe area, без фиксированной высоты страницы. Чат и формы сохраняются при переключении; панель плана использует сохранённые серверные данные. При 320 px длинные строки переносятся, действия становятся вертикальными.

Приветствие: компактный контекст, спокойный Спутник, серверный первый `next_steps`. Разговор: заголовок становится компактным, история не получает повторного приветствия. Ожидание: только у конкретного запроса, с именованием стороны ожидания; карта не изображает проценты и не задерживает ответ.

## Маскот

14.11.2026 пользователь выбрал **1 — Спутник** в ответ на показ [трёх эскизов](mascot-sketches/comparison.png). Материалы: [сравнение](mascot-sketches/comparison.html), SVG приветствия и ожидания в той же папке. Это собственные геометрические SVG, созданные для проекта без внешних ресурсов, не официальный персонаж Авито.

Реализован финальный набор после этого выбора: greeting, working, waiting-service, waiting-user, attention, complete. Спокойная поза при неизвестном исходе, без празднования. Нейтральный знак остаётся fallback. Все декоративные экземпляры скрыты от скринридера; статус объявляет карта.

## Поведение и проверки

Первый шаг строго `next_steps[0]`, без клиентского ранжирования. Прогресс: собственные шаги с `period === week`; числитель `done`, знаменатель все такие шаги. При нуле — «На этот период шагов пока нет». Отгул остаётся в заявках. Ожидания от других не считаются собственной выполненной работой.

Форма: Fieldset, постоянная подпись, подсказка, ошибка через aria-describedby, фокус первой ошибки, сохранённый ввод. Подтверждение: «Отправить заявку», «Отправить запрос на отгул», «Подтвердить отмену», актуальная версия. Техническая версия и режим модели раскрываются в деталях демо.

Движение контролов 160 мс; переход активного узла/позы 220 мс; короткая реакция ≤600 мс. Никакой очереди проигрывания: новый снимок показывается сразу. После refresh исторические переходы не анимируются. При stale нет перемещения; reduced motion выключает все переходы/пульсации. Ожидание человека статично.

Человеческая приёмка и ручная проверка скринридером пока не выполнены. Скриншоты эскизов не являются доказательством реализации рабочего экрана.

## Реализованные компоненты и примеры

| Область | Компоненты | Источник содержания |
|---|---|---|
| Контекст и главный шаг | WorkspaceContext, NextStep | профиль, первый next_steps |
| Разговор | ChatMessages, CardView, RequestForms | история и версии карточек API |
| Сводка периода | OnboardingSummary, periodProgress | собственные steps текущего week |
| Полный план | Dialog, PlanStep, ServiceRequest | серверные steps и requests |
| Исполнение | useExecutions, ExecutionRoutes, ExecutionMap | сохранённый снимок и события |
| Характер | Buddy, useEventMotion | выбранный SVG и текущий узел |

Финальный основной заголовок следующего шага — 28/34 на desktop и 26/30 на mobile: оптическая корректировка для длинных названий в основном столбце. Роль секции — 21/26, ответ — 15/22, вспомогательный текст — 13/18. Это применение исследованных принципов, не пиксельная копия публичного гайда. CSS: `components/tokens.css` и `features/workspace.css`.

Чат и незавершённые формы сохраняются при открытии плана. Тело диалога плана размонтируется при закрытии, его серверные данные остаются в Query. Развёрнутые технические сведения при повторном открытии можно раскрыть снова; черновик сообщения и параметры формы не теряются. Подробнее о шаге и заявке раскрываются через нативный details. У approved-доступа нет кнопки отмены, у blocked/сервисного/чужого шага нет ручной отметки. Эти решения отражают серверные поля и не заменяют серверную проверку прав.

Подтверждение доступа: ресурс и разрешённый уровень, обоснование и согласующий; действие «Отправить заявку». Подтверждение отгула: обе даты, число рабочих дней и согласующий; «Отправить запрос на отгул». Отмена — самостоятельная карточка и «Подтвердить отмену». Версия вынесена в «Технические сведения», маркировка «Демо» остаётся на первом плане. Ошибка группы связана с Fieldset и переводит фокус к первому полю; конфликт версии не стирает редактируемое значение.

| Реакция | Длительность | Условие |
|---|---:|---|
| Контрол | 160 мс | обычное взаимодействие |
| Перемещение к новому узлу | 220 мс | новый подтверждённый узел, свежая связь |
| Краткий отклик завершения | 360 мс | переход в completed без задержки результата |
| Первое открытие/refresh | 0 мс | сразу актуальная позиция |
| Stale/reduced motion | 0 мс | без перемещений и пульсации |

Сам SVG находится в `components/Buddy.tsx`; это локальные векторные части без сетевого ресурса. Fallback — нейтральный знак. Карта вынесена из live-region истории; у маскота aria-hidden, свой aria-live ему не добавляется. Диалоги используют нативные showModal/Escape и возврат фокуса.
