## Путь стажёра в первые недели

Каркас — общая вкладка [чек-листа](../sources/checklist.md): 1-я неделя (знакомство с командой, наставник, доступ в пространство команды) → 2-я неделя (документы команды, инструмент прогресса) → поздние этапы (вне прототипа). ### Ключевые решения по поведению агента

- Уточнения — по одному вопросу, кнопками с возможностью ответить текстом.
- Действие, меняющее состояние, — только через карточку с явным подтверждением. Карточку можно править полями или фразой в чат; любая правка — новая версия и новое подтверждение. Черновик ждёт 24 часа.
- Права проверяются на бэкенде до LLM, до карточки и повторно при подтверждении. Скрытое не раскрывается; видимое, но запрещённое — отказ с контактом.
- Статус меняется только по ответу сервиса-имитации или по отметке владельца шага. Таймаут — «результат уточняется»: автоматическая сверка, кнопка «Проверить сейчас», повтор закрыт.
- В демо статусы меняет ведущий через панель имитации; агент сообщает об изменениях первым.
- Без LLM доступ и отгул оформляются кнопочными формами с теми же проверками.
- Следующий шаг выбирает код, LLM только объясняет.
- Доступы стажёра — как у члена команды; данные по стратегии и финансам — «по задаче», с объяснением задачи ([ответы организаторов](../sources/organizers-qa.md)).
- Агент обращается на «ты» и не спрашивает причину отсутствия.

## Шаблон описания сценария

Создавайте файл `docs/scenarios/<kebab-name>.md` по шаблону:

```markdown
# <Название сценария>

## Проблема
Какую боль стажёра решает и какую рутину снимает с наставника.

## Пользователь и роли
Кто инициирует, какие права нужны, что видят другие роли.

## Путь пользователя
1. Стажёр пишет: «…»
2. AI-buddy …
3. …
4. Результат: …

## Действия через сервисы
Какой сервис (имитация), какая операция, что возвращает, где отображается и сохраняется результат.

## Ошибки и граничные случаи
Нет прав; сервис недоступен; LLM не ответила; неполные данные.

## Метрики
Как поймём, что сценарий приносит пользу (см. docs/metrics.md).

## Ссылки
- Спека: openspec/specs/<capability>/spec.md
```
