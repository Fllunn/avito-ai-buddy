# Проверка текущей реализации — 13.11.2026

Проверены `make coverage` и сборка. PostgreSQL-тесты выполняются на отдельном одноразовом Compose-проекте; основной демо-стенд не сбрасывался. Настоящая LLM не вызывается.

## Реализовано и проверено

- Миграции профилей, сессий, планов, назначений, документов и каталога. Повторный сид сохраняет изменённый прогресс. Две команды, четыре роли, изоляция ролей PostgreSQL.
- Демо-вход, ротация непрозрачной cookie, выход, серверный срок действия, проверка Origin и `/api/me`. Дополнительные поля роли и команды отклоняются.
- Чтение собственного плана с фильтрацией назначений; выбор следующего шага кодом. Чужой идентификатор в query не меняет владельца.
- Локальная очистка чувствительного ввода с закрытым режимом. Хранилище сообщений принимает только результат очистки, не исходный текст. Повторы client_message_id объединяются, конфликт очищенного содержимого отклоняется.
- Хранилище карточек: отдельные неизменяемые версии, замена, срок от последней правки, отмена без попытки действия, конкурирующие правки со старой версией.
- Подтверждение записывает снимок попытки и job одной транзакцией. Проверены двойной клик, разные карточки одного ресурса, отзыв прав во время предварительной проверки, чужая карточка и искусственный отказ записи job без частичного подтверждения.

## Границы готовности

Это ещё не сквозной продукт. Чат и карточки не подключены к UI; очередь пока не выполняет сервисные действия. Не завершены общий worker/сверка, API имитаций, инструменты, отгулы, провайдер диалога, Redis-кэш, метрики и итоговая приёмка. Наличие таблицы jobs не означает выполненную отправку. `/readyz` продолжает возвращать `BOOTSTRAP_ONLY`. Основной запущенный стенд требует пересборки для получения нового кода.

Реальная LLM отложена пользователем; это не препятствует реализации кнопочных сценариев и fake-провайдера. Change не принят и не архивирован.
