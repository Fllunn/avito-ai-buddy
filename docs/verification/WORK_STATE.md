Браузерный acceptance прошёл на последних образах: две команды, четыре роли, источники, две вкладки, created→approved→P6/P7, submitted/approved, перенос двумя подтверждениями, отмена и reload. Мобильный вид 390 px без горизонтального переполнения.

resilience проверяет двухсекундную задержку без блокировки UI, unavailable/повтор того же ключа, потерю ответа/один объект и сохранение владельца после logout. reset проверяет unknown/queued, частичный сбой с остановкой обработчиков, повторный согласованный сброс, отсутствие поздних отправок и отказ старой сессии. Перезапуск дополнительно подтвердил сохранение сессии, истории и версий объектов. Отмена доступа и переход материал → доступ проверены отдельными браузерными сценариями. Итоги в одноимённых JSON; только завершившиеся прогоны считаются доказательством.
