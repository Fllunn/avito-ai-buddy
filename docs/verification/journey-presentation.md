# Проверка представления маршрута

14.11.2026: `cd frontend && npm run coverage` — 49 тестов прошли, покрытие строк фронтенда 96,51% (305/316 по Vitest/V8). `npm run build` и `openspec validate --all --strict` прошли; `node scripts/check-redesign-links.mjs` проверил 80 локальных ссылок.

Компонентные тесты проверяют последовательность и дедупликацию подтверждённых событий, немедленный результат, восстановление маршрута, смену запроса, отмену при ошибке и устаревании, уменьшенное движение, две ветви переноса и общую позицию компактного и подробного вида. Проверка живого синтетического запроса показала подпись воспроизведения и импульс; реальная LLM не вызывалась. На desktop и узком viewport визуально проверена композиция плана. Фильтр чувствительных данных проверяет ограниченный набор шаблонов; он не гарантирует распознавание всех возможных данных.

Ручная проверка настоящего скринридера и экранной клавиатуры телефона не проводилась. Это не отчёт покрытия backend и mocks и не подтверждение человеческой приёмки.

На отдельном стенде проверены запрос доступа, ожидание подтверждения и сохранённый результат; на быстром запросе наблюдалось последовательное воспроизведение. Сквозной сценарий отгула не завершён: автоматизированный ввод даты показал значение в поле, но после отправки форма вернула ошибку и поля оказались пустыми. Не установлено, связано ли это с вводом через инструмент браузера или с приложением. Отказ и размеры 390/1024/1440 px в этом прогоне отдельно не проверены; задача 3.1 остаётся открытой.
